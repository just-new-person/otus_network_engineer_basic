#### 1. Количество бит подсети<br>
Количество бит подсети определяется маской подсети. В примере это 255.255.255.0, значит в этой маске под сеть используются три первых октета (3*8 = префикс /24), а под хосты остается свободен последний октет.<br>
Ответ: Количество бит подсети - 24
